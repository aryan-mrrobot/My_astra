Vulnerability Name : load scripts DOS vulnerability 
Vulnerable Domain : https://pbq.drexel.edu/

Description: 
WordPress allows users to load multiple JS files and CSS files through load-scripts.php files at once. For example,https://www.url.com/wp-admin/load-scripts.php?c=1&load%5B%5D=jquery-ui-core,editor&ver=4.9.1, file load-scripts.php will load jquery-ui-core and editor files automatically and return the contents of the file.
(check references for more details about the vulnerability)

Affected link/s = https://pbq.drexel.edu/wp-admin/load-scripts.php?c=1&load%5B%5D=jquery-ui-core&ver=4.9.1


the load-scripts.php file was receiving a parameter called load[]. This parameter is an array that was receiving the names of the JS files that needed to be loaded. In this case, it was receiving jQuery UI Core, which is the name of one of the Javascript files used by the WordPress login page. (it can be longer, this is just an example)
As no rate-limiting is setup for this URL - then DoS comes real

Mitigation:
3) how to fix
The web application firewall will mitigate attacks by adding the following to .htaccess -file:

<Files load-scripts.php>
Order allow, deny
Deny from all
</Files>
